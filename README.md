# Next Noticias

Base de un sitio web con HTML, CSS y JavaScript puro, sin frameworks ni dependencias.

## Iniciar

Abre `index.html` en tu navegador. No requiere instalación ni compilación.
También puedes usar la extensión Live Server de Visual Studio Code para ver los cambios al guardar.

## Estructura

```text
Next_Noticias/
├── index.html       # Página principal
├── css/styles.css   # Estilos del sitio
├── js/main.js       # JavaScript del sitio
├── .gitignore       # Exclusiones de Git
└── README.md
```

## Desarrollo

Edita el contenido en `index.html`, los estilos en `css/styles.css` y el comportamiento en `js/main.js`.
La página inicial incluye un diseño adaptable y actualiza el año del pie de página con JavaScript.
